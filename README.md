# p38_NFkB_single_cell_simulation

# TNF_Knock_out
Simulation for p38 and NFkB signal in single immune cells.
(The codes are tested in Matlab R2020a)

[Step 1]: Download the whole folder to local.

[Step 2]: In matlab, CHANGE the current folder to 'p38_NFkB_single_cell_simulation' (or the folder in which 'run_me.m' is). 

[Step 3]: create filefolder 'raw_data' under the current folder 'p38_NFkB_single_cell_simulation'.

[Step 4]: download the data_files for single cell simulation to the filefolder 'raw_data' at (website).

[Step 5]: Run 'run_me.m' to get all the simulation and results.

Output:
By default, it will create ./raw_data ./SubFigures2023 under the current folder in Matlab for saving data and figures.
